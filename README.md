# 원더스피크 레벨테스트

신규 상담자 말하기 레벨테스트 평가 → A4 결과지 인쇄·PDF 저장 (GitHub Pages + Supabase).
학생 기록은 이 저장소가 아니라 Supabase(시간표와 같은 `docs` 테이블, `leveltests` 컬렉션)에 있고, 학원 비밀번호로 로그인해야 보여요.

## 테스트 진행 (runner.html)

상담 → 말하기 진단(그림 묘사 포함) → 결과 정리 순서로 진행하는 선생님용 페이지예요.
`저장하고 결과지 열기`를 누르면 점수·Class·메모가 같은 `leveltests` 컬렉션에 저장되고, `index.html#open=<기록 id>`로 이동해 결과지가 바로 열려요.

## 학생 화면 (student.html)

상담할 때 학생에게 띄워 주는 화면이에요. 로그인 없이 열리고, 진행 페이지 상단의 `학생 화면 ↗` 링크로도 열 수 있어요.
